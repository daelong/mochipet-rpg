# 모찌펫 RPG · MochiPet RPG

**귀여운 친구를 돌보고, 함께 산책하고, 수동·자동 전투로 성장시키는 웹 펫 RPG입니다.**
React + Phaser + TypeScript 기반 **Phase 1 로컬 웹 MVP**를 추가했습니다. PC와 모바일에서 2D 맵이 화면을 가득 채우며, 양옆의 반투명 버튼으로 기능을 엽니다.

28종 캐릭터 선택, 자동 산책·전투, 8종 몬스터, 4개 사냥터, 고유 시작 스킬, 레벨업, 상점, 브라우저 저장을 구현했습니다. **싱글 최고 레벨은 20**이며, 계정·기기 간 동기화·온라인 월드는 아직 없습니다. 이 브라우저의 기록은 사용자가 수정할 수 있는 로컬 데이터이고, 향후 서버 보상 증빙으로 사용하지 않습니다.

## 빠른 실행

Node.js **22.12 이상**과 pnpm **10.28.2**를 준비합니다. 기존 Node 16으로는 실행할 수 없습니다.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

터미널에 표시되는 [로컬 게임](http://127.0.0.1:5173/)을 열고 **친구 선택하기 → 함께 모험하기 → 사냥터 선택·입장 → 몬스터 클릭 또는 자동사냥 ON** 순서로 시작하세요. 서버는 기본적으로 로컬 주소에만 바인딩합니다. Phase 1에는 DB나 API 서버가 필요하지 않으며, 환경 변수도 없습니다. [.env.example](.env.example)을 참고하세요.

```sh
pnpm test                 # 공통 게임 규칙·저장 복구 테스트
pnpm build                # 이미지·CSV 일치·TypeScript 검사 + 프로덕션 빌드
pnpm exec playwright install chromium  # 최초 브라우저 테스트 환경 준비
pnpm test:e2e             # PC / 모바일 크기 Chromium 자동화 검사
pnpm --filter @mochi/web preview --port 4173
```

프로덕션 빌드 출력은 `apps/web/dist/`입니다. 이를 HTTP 서버로 제공해야 하며 `index.html`을 파일로 직접 열어 실행하지 않습니다. 원격 서비스에는 HTTPS가 필요합니다. 정적 호스팅 공개 배포는 이번 작업에 포함하지 않았습니다.

## 플레이와 기록

- 십이지신 12종 + MBTI 테마 16종. 이름 변경과 친구 변경을 지원합니다. MBTI 설문은 아직 없으며 성격 진단으로 표현하지 않습니다.
- 펫 좌표·이동·애니메이션은 Phaser가 관리합니다. React는 상태와 메뉴를 표시하고, Zustand로 게임의 상태 변경을 전달합니다.
- 맵의 땅을 클릭하거나 터치하면 그곳으로 산책합니다. 왼쪽 버튼은 사냥·쓰다듬기·휴식, 오른쪽 버튼은 사냥터·친구·상점·스킬·기록·설정입니다. 패널은 같은 버튼, 닫기 버튼 또는 Esc로 닫습니다.
- 쓰다듬어도 산책·문으로 이동·사냥을 멈추지 않습니다. 약 1.8초 동안 하트와 가벼운 몸짓으로 기분 좋은 반응만 보이며, 친밀도·행복 보상은 기존처럼 5초 간격으로 제한합니다.
- 이동할 때는 실제 이동 방향으로 몸을 돌리고, 멈춰 사냥할 때는 현재 공격 대상을 바라봅니다. 원본 이미지는 좌우 반전 방식이며, 상하로만 이동할 때는 마지막 좌우 방향을 유지합니다.
- 맵을 마우스나 손가락으로 끌면 원하는 곳을 자유롭게 둘러봅니다. 드래그 뒤에는 캐릭터를 자동으로 따라가지 않으며, 아래쪽 반투명 **친구 따라가기** 버튼으로 복귀합니다. 드래그는 산책·가구 클릭으로 처리하지 않습니다. 활동 중에도 화면만 옮길 수 있고 활동은 계속됩니다.
- 처음 보이는 바깥은 **집 앞 마당**입니다. **우리 집** 버튼이나 집 문을 누르면 펫이 문 앞까지 걸어가 문을 통과한 뒤 실내로 들어갑니다. 마당 복귀도 실내 출입문 또는 사냥터 출입문까지 걸어서 이동하며, **이동 취소**나 땅 클릭으로 중단할 수 있습니다. 식탁·욕조·화장실·놀이 매트·책장·침대·청소 도구에서 밥 먹기, 목욕, 화장실, 놀이, 독서, 수면, 청소를 할 수 있습니다. 가구나 활동 버튼을 누르면 이동한 뒤 6~15초 동안 활동하며, 완료한 돌봄만 효과와 횟수가 저장됩니다. 기본 집 안 활동은 무료입니다.
- 집 안 활동을 누르면 **모찌 CAM**이 이동을 따라가고, 가구에 도착하면 활동 장면을 확대합니다. **방 전체 보기 / 활동 카메라**로 시점을 전환할 수 있으며, 완료·취소 시 기본 화면으로 돌아갑니다.
- **밥 먹기**에서는 펫 앞에 밥그릇을 놓고, 숟가락으로 밥을 떠서 입에 넣고 씹는 동작을 보여줍니다. 네 숟갈을 먹는 동안 그릇의 밥이 줄고 마지막에는 빈 그릇이 남습니다.
- 다른 집 안 활동도 소품을 직접 사용합니다. 욕조에서 스펀지로 씻고 샤워·수건으로 마무리하며, 공을 던지고 받아 인형을 안고, 책장을 넘기고, 이불을 덮고 숨 쉬며 잠듭니다. 화장실에서는 휴지·물 내리기·손 씻기, 청소에서는 빗자루와 쓰레받기로 먼지를 모아 치우는 과정을 보여줍니다.
- 청결·화장실 욕구·방 상태가 함께 변합니다. 마당과 집에는 몬스터가 없습니다. 사냥터 메뉴에서 지역을 골라 **입장**하면 별도의 모험 맵으로 이동합니다. 마당·집의 사냥 버튼은 입장할 사냥터를 고르는 메뉴를 엽니다. 활동 중 취소·외출·새로고침하면 남은 활동은 중단됩니다.
- 사냥터에는 최대 **5마리**의 몬스터가 서로 겹치지 않는 무작위 위치에 나타납니다. 처치한 자리는 **2.5초 간격**으로 1마리씩 보충됩니다. 자동사냥이 OFF여도 몬스터는 남아 있어 맵을 둘러볼 수 있습니다.
- **몬스터를 클릭·터치**하면 펫이 그 대상에게 이동해 일반 공격을 반복합니다. 자동사냥은 OFF로 두며, 선택한 한 마리를 처치하면 멈춥니다. 다른 몬스터를 눌러 대상을 바꾸거나 땅·**공격 중단**을 눌러 수동 공격을 취소합니다. 몬스터 위에서 맵을 끌어도 공격으로 처리하지 않습니다.
- 아래쪽 **스킬 버튼**으로 고유 스킬을 직접 사용합니다. 멀리 있다면 현재 대상에게 접근한 뒤 한 번 사용하며, 취소·대상 변경·퇴장하면 대기 중인 스킬도 취소됩니다. **자동사냥 시 스킬 자동 사용**을 끄면 자동사냥 중에도 스킬 사용 시점을 직접 정할 수 있습니다. 수동 전투에서는 버튼을 눌러야 스킬을 사용합니다.
- **자동사냥 ON**이면 가장 가까운 몬스터를 골라 접근하고, 처치 후 다음 대상을 찾아갑니다. 몬스터별 HP·중독·반격·보상을 구분하고 일반 공격과 쿨다운이 있는 고유 스킬을 사용합니다. 공격·중독·회복·방어 효과, HP 바, 피해 숫자, 보상을 표시합니다.
- 풀잎 초원 Lv.1 / 반짝 숲 Lv.3 / 바위 동굴 Lv.5 / 달빛 언덕 Lv.8. 레벨 20에서는 XP가 늘지 않고 코인은 계속 획득합니다.
- 음식·장난감은 구매 즉시 사용합니다. 훈련·최대 HP·스킬 강화에는 레벨 및 구매 한도가 있습니다. 신규 스킬 구매·인벤토리·장비는 다음 단계입니다.
- 자동사냥 중 HP가 25% 이하이거나 체력이 5 미만이면 안전하게 쉽니다. HP 75% 이상·체력 30 이상으로 회복하면 자동으로 재개합니다. 수동 공격 중에는 같은 기준에서 공격을 중단하며, 회복 후 다시 대상을 눌러 시작합니다. **자동사냥 OFF**, 수동 쉬기, 집·마당 이동으로 전투를 끝낼 수 있습니다. 플레이 화면이 숨겨지거나 본 탭을 닫으면 게임 진행을 멈추며, 자리 비움 보상은 없습니다.
- **설정 → 미니 펫 창 · PiP → 미니 창 열기**로 작은 별도 창에서 플레이합니다. 자동사냥·먹이·본 화면 복귀 버튼을 제공하고 같은 펫·캔버스·기록을 이어갑니다. PiP 창이 보이는 동안에는 본 탭을 떠나도 진행합니다. 본 탭은 열어 두어야 하며, 미니 창을 닫으면 원래 화면으로 돌아옵니다. 브라우저 절전·최소화로 진행이 멈출 수 있습니다. HTTPS/localhost의 Document PiP 지원 PC 브라우저에서만 활성화하며, 미지원 환경은 일반 화면으로 플레이합니다.
- 10초마다, 구매·선택·이름 변경 후, 탭을 떠날 때 브라우저에 저장합니다. 새로고침 후 수동·자동 공격과 스킬 대기는 OFF입니다. 스킬 자동 사용 선택은 현재 세션에만 적용합니다.
- 이전 정상 기록 복구, 미래 저장 버전 보호, 초기화 확인·원본 백업, 기록 내보내기를 지원합니다. 초기화 백업은 마지막 1회이며 외부 파일 가져오기는 아직 없습니다.
- 집 안 기능의 저장 형식은 v2입니다. 기존 v1 기록의 성장·코인·구매 내역을 유지해 이전하고, 첫 저장 전에 원본을 별도 백업합니다. 이 원본은 설정의 기록 내보내기에도 포함됩니다.
- Web Locks로 중복 탭의 진행과 저장을 막습니다. 지원하지 않거나 잠금을 얻지 못하면 읽기 전용 화면을 제공합니다. 브라우저 데이터 삭제와 비공개 모드는 영구 보관을 보장하지 않습니다.

## 보존한 Godot 프로젝트

기존 **Godot 4.7.2 Standard + GDScript, v0.4.1-review** 소스와 저장 스키마, 백업, 중복 실행 가드, 레벨 20 상한, 일반 창 기본값을 유지했습니다. 웹과 Godot는 런타임·저장·빌드를 공유하지 않습니다. 옛 Python/Go/JXA 실행판을 추가하지 않았습니다.

```sh
python3 tests/static_audit.py
python3 -m unittest discover -s tests -p 'test_repository.py' -v
```

위 두 Python 검사는 정적 정책과 저장소 구성을 확인하며 **Godot 실행·백신 검사·안전 인증이 아닙니다**. Godot 파싱과 플랫폼별 설치·실행 검증은 별도로 필요합니다. EXE·Mac 앱은 생성하지 않았습니다.

`node_modules/`, 브라우저 테스트 산출물, 개인 저장·비밀키는 Git에서 제외합니다. 현재 웹 미리보기 출력은 `apps/web/dist/`에도 포함되어 있으며, Windows/macOS 설치판은 만들지 않았습니다. `.uid`와 이미지 `.import`는 제외하지 않습니다. 라이선스와 이미지 권리를 결정하기 전에는 Private 저장소로 관리하는 편을 권합니다. 자동 배포나 GitHub Actions는 추가하지 않았습니다.
