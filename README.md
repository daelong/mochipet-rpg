# 모찌펫 RPG · MochiPet RPG

**Godot + GDScript로 만드는 데스크톱 펫 육성·사냥 RPG의 개발 저장소입니다.**
십이지신/MBTI 캐릭터를 키우고 화면에서 몬스터와 싸우며, 코인으로 먹이·장난감·능력치·스킬 강화를 구매하는 게임을 목표로 합니다.

> 현재 기준: **v0.4.1-review 소스**. EXE나 Mac 앱은 들어 있지 않습니다.
> 게임 실행·설치·보안 검증을 완료한 출시판이 아닙니다. **바탕화면 오버레이는 꺼져 있고 일반 창이 기본**입니다.
> 이 저장소 정리는 게임 기능을 새로 구현하거나 이전 실행 파일을 업데이트하는 작업이 아닙니다.

## 현재 들어 있는 코드

| 항목 | 소스 기준 상태 |
|---|---|
| 캐릭터 | 십이지신 12 + MBTI 16 = 28종 선택 데이터와 이미지 |
| 전투 | 몬스터 1마리 생성, 접근·자동 공격·피해 표시·처치 보상 |
| 사냥터 | 4곳, 입장 레벨 1 / 5 / 10 / 15, 몬스터 8종 |
| 상점 | 음식·장난감·공격/방어/민첩 훈련·스킬 강화·회복의 7개 항목 |
| 성장 | 경험치·코인, 오프라인 레벨 상한 20 |
| 스킬 | 캐릭터별 스킬 이름 + 공통 강화 수치. 개별 고유 효과·스킬 트리는 미구현 |
| 저장 | JSON 검증·백업·초기화 확인·중복 실행 가드 코드 |
| 화면 | 일반 창 기본. 투명 바탕화면 모드는 미검증으로 비활성화 |
| 온라인 | 계정·서버·멀티플레이 미구현. 레벨 20 안내 문구만 있음 |

이는 코드 검토로 확인한 구성 설명이며 실제 게임 실행 성공을 의미하지 않습니다.
MBTI 설문 검사·추천 알고리즘도 아직 없습니다. 자세한 내용은 [현재 상태](docs/PROJECT_STATUS.md)를 확인하세요.

## 개발 시작

기존 소스의 목표 버전 **Godot 4.7.2 Standard**를 유지했습니다. 다른 버전에서의 호환성을 확인한 것은 아닙니다.
Godot에서 `project.godot`을 가져와 파싱 오류부터 확인하세요. 개발자용 상세 명령은 [개발 안내](docs/DEVELOPMENT.md)에 있습니다.

게임을 실행하지 않는 로컬 검사:

```sh
python3 tests/static_audit.py
python3 -m unittest discover -s tests -p 'test_repository.py' -v
```

Windows에서 `python3` 대신 설치된 Python 명령인 `py -3` 또는 `python`을 사용할 수 있습니다.
Python은 위 개발용 검사 도구에만 사용하며, 게임 코드는 GDScript입니다.

## 저장소 관리 원칙

소스·씬·원본 게임 이미지·검사 코드·설치기 소스는 함께 관리합니다.
`.godot/`, 실행 파일, 개인 저장기록, 서명키, 토큰은 올리지 않습니다. `.uid`와 이미지의 `.import` 보조 파일은 Godot에서 생성되면 함께 커밋합니다.
현재의 작은 PNG에는 Git LFS를 설정하지 않았습니다.

**처음에는 Private 저장소로 보관하는 것을 권합니다.** 공개·상용 배포 전에는 코드와 캐릭터 이미지의 권리 및 라이선스 정책을 따로 결정해야 합니다.
MIT 등 공개 라이선스를 임의로 붙이지 않았습니다. [라이선스 정책](LICENSE_POLICY.md)을 확인하세요.

## 중요한 제한

이 묶음에는 옛 Python/JXA/Go 실행판이나 자동 다운로드 설치기가 들어 있지 않습니다.
게임 소스와 이미지의 기존 경로·내용을 유지하여 GitHub 관리 파일만 보강했습니다.
자동 EXE 빌드, GitHub Actions 워크플로, 서버 배포는 이번에 추가하지 않았습니다.
저장소에 올리는 것과 게임을 빌드·검증·출시하는 것은 별도 단계입니다.
