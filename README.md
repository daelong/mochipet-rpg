# 모찌펫 RPG · MochiPet RPG

**귀여운 친구를 돌보고, 함께 산책하고, 자동 전투로 성장시키는 웹 펫 RPG입니다.**
React + Phaser + TypeScript 기반 **Phase 1 로컬 웹 MVP**를 추가했습니다. PC와 모바일에서 2D 맵이 화면을 가득 채우며, 양옆의 반투명 버튼으로 기능을 엽니다.

28종 캐릭터 선택, 자동 산책·전투, 8종 몬스터, 4개 사냥터, 고유 시작 스킬, 레벨업, 상점, 브라우저 저장을 구현했습니다. **싱글 최고 레벨은 20**이며, 계정·기기 간 동기화·온라인 월드는 아직 없습니다. 이 브라우저의 기록은 사용자가 수정할 수 있는 로컬 데이터이고, 향후 서버 보상 증빙으로 사용하지 않습니다.

## 빠른 실행

Node.js **22.12 이상**과 pnpm **10.28.2**를 준비합니다. 기존 Node 16으로는 실행할 수 없습니다.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

터미널에 표시되는 [로컬 게임](http://127.0.0.1:5173/)을 열고 **친구 선택하기 → 함께 모험하기 → 사냥 ON** 순서로 시작하세요. 서버는 기본적으로 로컬 주소에만 바인딩합니다. Phase 1에는 DB나 API 서버가 필요하지 않으며, 환경 변수도 없습니다. [.env.example](.env.example)을 참고하세요.

```sh
pnpm test                 # 공통 게임 규칙·저장 복구 테스트
pnpm build                # 이미지·CSV 일치·TypeScript 검사 + 프로덕션 빌드
pnpm exec playwright install chromium  # 최초 브라우저 테스트 환경 준비
pnpm test:e2e             # PC / 모바일 크기 Chromium 자동화 검사
pnpm --filter @mochi/web preview --port 4173
```

프로덕션 빌드 출력은 `apps/web/dist/`입니다. 이를 HTTP 서버로 제공해야 하며 `index.html`을 파일로 직접 열어 실행하지 않습니다. 원격 서비스에는 HTTPS가 필요합니다. 정적 호스팅 공개 배포는 이번 작업에 포함하지 않았습니다.

## 플레이와 기록

- 십이지신 12종 + MBTI 테마 16종. 이름 변경과 친구 변경을 지원합니다. MBTI 설문은 아직 없으며 성격 진단으로 표현하지 않습니다.
- 펫 좌표·이동·애니메이션은 Phaser가 관리합니다. React는 상태와 메뉴를 표시하고, Zustand로 게임의 상태 변경을 전달합니다.
- 맵의 땅을 클릭하거나 터치하면 그곳으로 산책합니다. 왼쪽 버튼은 사냥·쓰다듬기·휴식, 오른쪽 버튼은 사냥터·친구·상점·스킬·기록·설정입니다. 패널은 같은 버튼, 닫기 버튼 또는 Esc로 닫습니다.
- 맵을 마우스나 손가락으로 끌면 원하는 곳을 자유롭게 둘러봅니다. 드래그 뒤에는 캐릭터를 자동으로 따라가지 않으며, 아래쪽 반투명 **친구 따라가기** 버튼으로 복귀합니다. 드래그는 산책·가구 클릭으로 처리하지 않습니다. 활동 중에도 화면만 옮길 수 있고 활동은 계속됩니다.
- 처음 보이는 바깥은 **집 앞 마당**입니다. **우리 집** 버튼이나 집을 눌러 실내로 들어갑니다. 식탁·욕조·화장실·놀이 매트·책장·침대·청소 도구에서 밥 먹기, 목욕, 화장실, 놀이, 독서, 수면, 청소를 할 수 있습니다. 가구나 활동 버튼을 누르면 이동한 뒤 6~15초 동안 활동하며, 완료한 돌봄만 효과와 횟수가 저장됩니다. 기본 집 안 활동은 무료입니다.
- 집 안 활동을 누르면 **모찌 CAM**이 이동을 따라가고, 가구에 도착하면 활동 장면을 확대합니다. **방 전체 보기 / 활동 카메라**로 시점을 전환할 수 있으며, 완료·취소 시 기본 화면으로 돌아갑니다.
- **밥 먹기**에서는 펫 앞에 밥그릇을 놓고, 숟가락으로 밥을 떠서 입에 넣고 씹는 동작을 보여줍니다. 네 숟갈을 먹는 동안 그릇의 밥이 줄고 마지막에는 빈 그릇이 남습니다.
- 다른 집 안 활동도 소품을 직접 사용합니다. 욕조에서 스펀지로 씻고 샤워·수건으로 마무리하며, 공을 던지고 받아 인형을 안고, 책장을 넘기고, 이불을 덮고 숨 쉬며 잠듭니다. 화장실에서는 휴지·물 내리기·손 씻기, 청소에서는 빗자루와 쓰레받기로 먼지를 모아 치우는 과정을 보여줍니다.
- 청결·화장실 욕구·방 상태가 함께 변합니다. 마당과 집에는 몬스터가 없으며, 사냥을 시작하거나 사냥터를 고르면 모험 지역으로 이동합니다. 활동 중 취소·외출·새로고침하면 남은 활동은 중단됩니다.
- 몬스터에 접근한 뒤 일반 공격과 쿨다운이 있는 고유 스킬을 사용합니다. 공격·중독·회복·방어 효과, HP 바, 피해 숫자, 보상을 표시합니다.
- 풀잎 초원 Lv.1 / 반짝 숲 Lv.3 / 바위 동굴 Lv.5 / 달빛 언덕 Lv.8. 레벨 20에서는 XP가 늘지 않고 코인은 계속 획득합니다.
- 음식·장난감은 구매 즉시 사용합니다. 훈련·최대 HP·스킬 강화에는 레벨 및 구매 한도가 있습니다. 신규 스킬 구매·인벤토리·장비는 다음 단계입니다.
- HP가 낮거나 체력이 부족하면 자동으로 사냥을 중단하고 쉽니다. 탭을 숨기거나 닫으면 게임 진행을 멈추며, 자리 비움 보상은 없습니다.
- 10초마다, 구매·선택·이름 변경 후, 탭을 떠날 때 브라우저에 저장합니다. 새로고침 후 사냥은 OFF입니다.
- 이전 정상 기록 복구, 미래 저장 버전 보호, 초기화 확인·원본 백업, 기록 내보내기를 지원합니다. 초기화 백업은 마지막 1회이며 외부 파일 가져오기는 아직 없습니다.
- 집 안 기능의 저장 형식은 v2입니다. 기존 v1 기록의 성장·코인·구매 내역을 유지해 이전하고, 첫 저장 전에 원본을 별도 백업합니다. 이 원본은 설정의 기록 내보내기에도 포함됩니다.
- Web Locks로 중복 탭의 진행과 저장을 막습니다. 지원하지 않거나 잠금을 얻지 못하면 읽기 전용 화면을 제공합니다. 브라우저 데이터 삭제와 비공개 모드는 영구 보관을 보장하지 않습니다.

## 보존한 Godot 프로젝트

기존 **Godot 4.7.2 Standard + GDScript, v0.4.1-review** 소스와 저장 스키마, 백업, 중복 실행 가드, 레벨 20 상한, 일반 창 기본값을 유지했습니다. 웹과 Godot는 런타임·저장·빌드를 공유하지 않습니다. 옛 Python/Go/JXA 실행판을 추가하지 않았습니다.

```sh
python3 tests/static_audit.py
python3 -m unittest discover -s tests -p 'test_repository.py' -v
```

위 두 Python 검사는 정적 정책과 저장소 구성을 확인하며 **Godot 실행·백신 검사·안전 인증이 아닙니다**. Godot 파싱과 플랫폼별 설치·실행 검증은 별도로 필요합니다. EXE·Mac 앱은 생성하지 않았습니다.

`node_modules/`, 빌드 출력, 브라우저 테스트 산출물, 개인 저장·비밀키는 Git에서 제외합니다. `.uid`와 이미지 `.import`는 제외하지 않습니다. 라이선스와 이미지 권리를 결정하기 전에는 Private 저장소로 관리하는 편을 권합니다. 자동 배포나 GitHub Actions는 추가하지 않았습니다.
