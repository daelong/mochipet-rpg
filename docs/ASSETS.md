# 이미지 리소스와 출처

이번 저장소의 이미지는 모두 대화에서 제공된 `MochiPet_Godot_v0.4.1_Security_Review_Source.zip`에서 가져왔습니다.
온라인에서 새 이미지를 내려받거나 그림을 추가 생성한 작업은 아닙니다.

| 디렉터리 | 내용 | 파일 수 |
|---|---|---:|
| `assets/pets/` | 28개 캐릭터 × 7개 상태 × 2프레임 | 392 |
| `assets/monsters/` | 몬스터 8종 | 8 |

상태 이름은 `idle`, `walk`, `play`, `eat`, `happy`, `sad`, `sleep`입니다.
파일명은 예를 들어 `assets/pets/z_rabbit/walk_0_right.png` 형식입니다.
7가지 상태 이미지가 존재한다는 것은 모든 행동 전환 시스템이 구현되어 있다는 뜻이 아닙니다.

이번 정리는 이미지 바이트를 바꾸지 않습니다. 기존 `docs/static_results.json`에는 이미지별 SHA-256이 있습니다.
대화 초기에 생성된 컨셉 이미지/선택표, 개인 스크린샷, 이전 실행판 전체는 현재 게임에 필요하지 않아 제외했습니다.
원본 제작/편집 과정의 권리 증빙까지 확인한 것은 아닙니다. 공식 배포 전 캐릭터 디자인·명칭·이미지 사용 범위를 검토해야 합니다.

캐릭터별 파일 경로와 기본 스킬명은 [characters.csv](catalogs/characters.csv)에 있습니다.
모든 PNG는 현재 크기 기준으로 일반 Git 파일로 관리하도록 구성했고 LFS 포인터로 변환하지 않았습니다.
대형 원화·영상·음원을 추가하기 전에는 Git LFS 정책을 별도로 정하세요.

공식 안내: https://docs.godotengine.org/en/stable/tutorials/best_practices/version_control_systems.html

## 웹 Phase 1에서의 재사용

2026-11-05 작업 시작 시 이 체크아웃에는 `assets/` 대신 `assets.zip`만 있었습니다. 압축 안의 경로를 검증해 `assets/`에 400개 PNG를 복원했고 모든 파일을 압축 원본과 SHA-256으로 비교했습니다. 원본 압축은 파일을 삭제하지 않고 작업 환경의 임시 백업 위치로 옮겼으며, Git에서는 압축 대신 실제 이미지 소스를 관리합니다. 이미지 바이트와 기존 경로를 변경하지 않았습니다.

웹게임은 `tools/assets.mjs`로 동일 리소스를 제공·복사합니다. 무대 배경은 Phaser 도형으로 그렸고, 상점·사냥터에는 시스템 이모지와 Lucide 아이콘을 사용합니다. 추가 이미지 생성·외부 이미지 다운로드는 하지 않았습니다. 원본 이미지의 두 프레임이 같은 동작도 있어, 위치 보간·작은 상하 움직임·반전으로 산책을 보완했습니다. 미술·애니메이션 품질 검수는 별도로 필요합니다.

집 안 식사 동작은 원본 캐릭터 위에 Phaser 도형으로 손·숟가락·입과 볼 움직임을 합성합니다. 앞쪽 식탁·밥그릇·줄어드는 밥도 코드로 그리며, 원본 PNG의 바이트·경로는 바꾸지 않습니다. 브라우저 검사에서 만든 식사 영상은 게임 캔버스를 기록한 임시 검수 자료이며 배포 리소스에 포함하지 않습니다.

나머지 여섯 활동도 `CareAnimation.ts`의 도형과 원본 캐릭터를 합성합니다. 스펀지·샤워기·수건, 공·곰 인형, 펼쳐 넘기는 책, 호흡에 따라 움직이는 이불, 빗자루·쓰레받기, 화장실 소품을 손과 연결해 그립니다. 수면 중 눈을 감는 표현을 추가하며, 동작 시간은 활동 시뮬레이션을 따릅니다. 추가 비트맵·외부 이미지·음원은 사용하지 않았습니다.
