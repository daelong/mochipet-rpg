- **설정 → 미니 펫 창 · PiP → 미니 창 열기**로 조작 가능한 작은 창을 엽니다. Document PiP API·HTTPS/localhost·최상위 문서를 검사하고, 준비되지 않았거나 읽기 전용인 세션에서는 열기를 차단합니다. 미지원 환경에서는 이유를 표시하고 일반 게임 화면을 유지합니다. 브라우저가 열기를 거부해도 기존 캔버스와 기록을 유지하며 재시도 안내를 보여줍니다.

# 사냥터 별도 입장·최대 5마리·자동사냥 변경·검증 · 이전 작업 (2026-11-06)

## 구현한 것

- 집·마당의 **사냥터 입장** 또는 사냥터 메뉴에서 지역을 골라 별도 모험 맵으로 입장합니다. 입장 후 패널이 닫히며 **자동사냥 ON**을 직접 켭니다. **마당으로** 버튼으로 나가면 모든 전투·자동 회복을 끝내고 몬스터를 정리합니다. 지역 레벨 제한은 유지했습니다.
- 사냥터 입장 시 해당 지역의 몬스터 5마리를 무작위 위치에 배치합니다. 최소 150 게임 좌표 간격을 두며, 난수 선택이 반복되어도 제한된 횟수 뒤 비어 있는 격자 위치를 찾아 겹침과 무한 반복을 피합니다. 종류와 위치를 매 입장마다 다시 고릅니다. 처치 후 2.5초 간격으로 1마리씩 보충하고 동시 수량은 최대 5마리입니다.
- 몬스터마다 인스턴스 ID·HP·중독 횟수/시간·반격 시간을 구분합니다. 같은 종류가 여러 마리 있어도 HP와 보상이 공유되지 않습니다. 피해·처치 효과는 해당 몬스터 위치에 표시합니다. 자동사냥 OFF에서는 몬스터가 남아 있지만 피해나 보상을 진행하지 않습니다.
- 자동사냥은 가장 가까운 살아 있는 몬스터를 골라 접근하고 일반 공격·고유 스킬로 싸웁니다. 현재 대상을 끝낸 뒤 다음 가까운 대상을 선택합니다. 공격 거리 측정에 인스턴스 ID를 함께 전달해, 처치 직전의 거리 판정이 다른 몬스터의 피해로 재사용되지 않게 했습니다.
- HP 25% 이하 또는 체력 5 미만이면 자동 회복에 들어갑니다. HP 75% 이상·체력 30 이상이면 자동사냥을 재개합니다. 처음부터 HP/체력이 낮아도 ON으로 두면 먼저 쉬고 시작합니다. OFF·수동 쉬기·집/마당 이동은 자동 재개를 취소합니다.
- 현재 몬스터 수·공격 대상 표시·몬스터 HP·접근 가능한 화면 설명을 제공합니다. 모바일의 입장 안내는 마당 복귀 버튼과 겹치지 않도록 위쪽에 표시합니다. 자유 시점·카메라 드래그·집 안 활동을 유지했습니다.
- 저장 스키마 v2, v1 이전 백업, 초기화 확인, 중복 탭 잠금, 오프라인 최대 레벨 20을 유지했습니다. 몬스터·대상·현재 장소·자동사냥·회복 진행은 저장하지 않으므로 새로고침하면 마당에서 사냥 OFF로 시작합니다. 숨겨진 탭에서는 진행하지 않고 자리 비움 보상도 없습니다.

기존 `assets.zip`에서 PNG 400개를 복원해 `assets/pets/`와 `assets/monsters/`의 원래 경로를 유지했습니다. 압축 원본과 복원본의 모든 SHA-256이 같았습니다. 압축 원본은 작업 환경의 임시 백업에 보관하고 저장소에서는 실제 PNG 소스로 대체합니다.

처음부터 누락되어 기존 저장소 검사를 실패시켰던 `.gitattributes`, `.editorconfig`를 추가했습니다. 기존 Python 검사는 웹 의존성·생성된 빌드/테스트 결과를 소스 스캔에서 제외하도록 디렉터리 순회만 보완했습니다. Godot 로직·저장 스키마·일반 창 설정·레벨 상한은 변경하지 않았습니다. `.uid`와 `.import`를 무시하지 않습니다.

## 실행 방법

Node.js 22.12 이상, pnpm 10.28.2:

```sh
pnpm install --frozen-lockfile
pnpm dev
```

`http://127.0.0.1:5173/`에서 친구를 선택하고 사냥 ON을 누릅니다. DB·API 서버·환경 변수는 필요하지 않습니다. `.env.example`은 Phase 1에 비밀값이 필요 없다는 안내입니다.

```sh
pnpm test
pnpm build
pnpm exec playwright install chromium
pnpm test:e2e
MOCHI_E2E_PRODUCTION=1 pnpm test:e2e
```

마지막 명령은 빌드 결과를 4173의 임시 미리보기 서버에서 검사합니다. 테스트가 끝나면 해당 서버를 종료합니다. Windows PowerShell에서는 먼저 `$env:MOCHI_E2E_PRODUCTION = '1'`로 지정한 뒤 `pnpm test:e2e`를 실행합니다.

## 실행하지 못한 검사·알려진 한계

- 실제 Windows·Android·iOS 기기, Safari·Firefox, PWA 설치, Document Picture-in-Picture, 화면 읽기 보조기술 검증은 수행하지 않았습니다. 모바일 Chromium 에뮬레이션을 실기기 검사로 표시하지 않습니다.
- 30 FPS는 렌더링 설정 목표입니다. CPU·메모리·배터리·장시간 실행·저사양 기기 성능은 측정하지 않았습니다.
- 새 캐릭터는 필요한 이미지들을 로딩합니다. 네트워크 장애 시의 고급 재시도·오프라인 캐시·모든 리소스의 스프라이트 시트 최적화는 다음 작업입니다. 기존 2프레임 이미지의 품질에는 한계가 있습니다.
- 로컬 상태는 수정할 수 있습니다. 브라우저 시계·저장 기록·클라이언트 계산을 서버 보상이나 온라인 자격으로 신뢰하지 않습니다.
- 탭이 숨겨지면 진행을 멈추고 재접속 시 사냥은 OFF입니다. 자리 비움 보상, 창 밖 펫, 미니 창은 없습니다.
- 계정·DB·Prisma 스키마/마이그레이션·API·서버 트랜잭션·온라인/다기기 동기화·멀티플레이는 미구현입니다. 빈 API를 실제 서버처럼 제공하지 않았습니다.
- 인벤토리·장비·추가 스킬 습득/장착·MBTI 질문 추천·PWA·Capacitor 앱은 미구현입니다. 현재는 친구의 고유 시작 스킬과 강화만 제공합니다.
- 저장 복구는 브라우저 저장소의 정상 쓰기를 전제로 합니다. 데이터 삭제·디스크 손상·전원 손실·개인 백업 파일의 가져오기는 보장하지 않습니다. 저장 실패 시 알림을 표시하고 다음 저장에서 재시도합니다.
- Godot 실행 파일이 준비되지 않아 가져오기·파싱·저장/리소스 런타임 테스트를 수행하지 않았습니다. Windows 설치기·EXE·Mac 앱·백신·서명·보안 인증·실제 서비스 배포도 수행하지 않았습니다.
- 게임 경제와 난이도는 초안 수치이며, 장기 플레이 밸런스는 검증하지 않았습니다. 코드·이미지의 공개 라이선스와 권리 검토는 소유자의 결정이 필요합니다.
