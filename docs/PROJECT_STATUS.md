## 현재 기본 수치

캐릭터 `z_rabbit`, 이름 모찌, 레벨 1, 코인 60, HP 60, 배부름 82, 기분 80, 공격력 7, 방어력 2, 민첩 1로 시작합니다.
최대 HP는 `60 + (레벨 - 1) × 7`, 다음 레벨 필요 경험치는 `35 + 레벨 × 20`입니다.
몬스터 처치 시 지역 기본 코인에 0~8이 더해지고, 지역 경험치를 받습니다.
피해량에 포함된 스킬 강화는 모든 캐릭터에 공통으로 `강화 수치 × 3`을 더합니다.
“독니”, “회복” 등의 이름이 표시되더라도 현재 별도의 중독·회복 효과가 구현된 것은 아닙니다.

사냥터·캐릭터 목록은 [캐릭터 CSV](catalogs/characters.csv), [사냥터 CSV](catalogs/zones.csv), [상점 CSV](catalogs/shop.csv)를 참고하세요.
CSV는 읽기용으로 추출한 자료입니다. **게임은 현재 CSV를 읽지 않고 GDScript 상수를 사용**합니다. 값을 바꾸면 양쪽 문서를 같이 갱신해야 합니다.
